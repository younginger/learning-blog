# 一、强化学习的数学基础
## 1.马尔可夫决策过程MDP(强化学习的语法)
任何强化学习问题，无论是大模型对齐(RLHF)还是控制机器人，在底层都可以被抽象为一个MDP。MDP由一个五元组构成:$(S,A,P,R,\gamma)$。
- $S$ (State - 状态): 环境对智能体的描述。比如视觉任务中，状态可以是当前帧的图像特征。
- $A$ (Action - 动作): 智能体可以执行的操作。比如相机云台的移动角度，或者大模型生成的下一个 Token。
- $P(s'|s, a)$ (Transition Probability - 状态转移概率): 环境的动态特性。表示在状态 $s$ 下执行动作 $a$ 后，转移到下一个状态 $s'$ 的概率。注意：这体现了环境的随机性。
- $R(s, a, s')$ (Reward - 奖励): 标量反馈信号。比如大模型输出的回复被人类点赞（+1）或踩（-1）。
- $\gamma$ (Discount Factor - 折扣因子): 介于 0 到 1 之间的数值。它决定了智能体是更看重眼前的奖励，还是未来的长远收益。
## 2.贝尔曼体系
在监督学习中我们要找的是最优权重W;在强化学习中，我们要找的是最优策略（Optimal Policy, $\pi^*$）。策略 $\pi(a|s)$ 就是在状态 $s$ 下选择动作 $a$ 的概率分布。
### 2.1价值函数
为了评价一个策略的好坏，我们定义了价值函数:$$V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{t=0}^{\infty} \gamma^t R_{t+1} \mid S_0 = s \right]$$
这个公式的含义就是从状态s出发，遵循策略 $\pi$，未来能拿到的所有奖励的折现总和的期望。
而贝尔曼方程最伟大之处，在于它将这个无限期的累加过程，拆解成了当前的即时奖励加上下一个状态的价值，这是一种完美的递归关系（非常类似动态规划中的子问题拆解）：$$V^\pi(s) = \sum_{a \in A} \pi(a|s) \sum_{s' \in S} P(s'|s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]$$如果我们要寻找最优策略，就会推导出贝尔曼最优方程：在每个状态下，我们总是贪婪地选择那个能让未来期望价值最大的动作：$$V^*(s) = \max_a \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]$$

我们可以把这两个方程拆解为三个层面的深刻认知:

贝尔曼方程做的实际上是将总价值分解为了此刻的价值和未来的潜力价值。在没有贝尔曼方程之前，如果要计算一个状态的价值 $V^\pi(s)$，我们需要用蒙特卡洛（Monte Carlo）思想去算期望。也就是从状态 $s$ 开始，让智能体跑完无数条轨迹（Trajectory），计算每条轨迹的累积折扣奖励 $G_t$：$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots$$然后对这些无限长的序列求平均：$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$。这在计算上是灾难性的：轨迹长度可能是无限的，且随着步数增加，状态空间呈指数级爆炸。贝尔曼做了一个绝妙的代数变换，他提取了公因式 $\gamma$：$$G_t = R_{t+1} + \gamma (R_{t+2} + \gamma R_{t+3} + \dots) = R_{t+1} + \gamma G_{t+1}$$,代入期望公式得到贝尔曼期望方程：$$V^\pi(s) = \sum_{a \in A} \pi(a|s) \sum_{s' \in S} P(s'|s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]$$

当我们评估一个固定的策略 $\pi$ 时（也就是第一个公式），因为 $\pi(a|s)$ 和环境的转移概率 $P(s'|s, a)$ 都是固定的常数，这个看似复杂的求和公式，本质上就是一个极度纯粹的线性方程组。我们可以把它写成矩阵和向量的形式：$$V^\pi = R^\pi + \gamma P^\pi V^\pi
$$其中，$V^\pi$ 是一个列向量，维度是状态数量 $N$。$R^\pi$ 是在策略 $\pi$ 下每个状态的期望即时奖励向量。$P^\pi$ 是状态转移概率矩阵（一个 $N \times N$ 的马尔可夫矩阵）。移项，提取 $V^\pi$：$$(I - \gamma P^\pi) V^\pi = R^\pi$$这是一个标准形如 $Ax = b$ 的线性系统。只要我们知道环境的规则（即矩阵 $P^\pi$），我们甚至不需要迭代，直接对矩阵求逆就能得到所有状态的精确价值：$$V^\pi = (I - \gamma P^\pi)^{-1} R^\pi$$(注：因为转移矩阵 $P^\pi$ 的特征值都在单位圆内或上，且 $\gamma < 1$，所以 $(I - \gamma P^\pi)$ 一定是可逆的。)这就是策略评估（Policy Evaluation）的数学本质。

现在来看第二个公式：贝尔曼最优方程。$$V^*(s) = \max_a \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]$$这里出现了一个极具破坏性的操作符：$\max_a$。因为 $\max$ 是一个非线性算子，最优方程不再是一个线性方程组了。这意味着我们无法用矩阵求逆来直接解出最优价值 $V^*$。这也是为什么在复杂的环境中，寻找最优策略极其困难的原因。那怎么求解？这里就要用到巴拿赫不动点定理（Banach Fixed-Point Theorem）。我们可以把方程右边看作一个算子 $B$（Bellman Optimality Operator）作用在价值函数向量 $V$ 上：$$V_{k+1} = B(V_k)$$在数值分析中，只要算子 $B$ 是一个压缩映射（Contraction Mapping），那么无论初始的 $V_0$ 瞎猜成什么样子，反复执行 $V_{k+1} = B(V_k)$，序列最终都一定会收敛到一个唯一的“不动点”，这个不动点就是我们梦寐以求的最优价值函数 $V^*$。

### 2.2动作价值函数
如果只知道最优的V*(s),智能体在做决策时，依然需要知道环境的转移矩阵$P(s'|s, a)$才能推算哪一步最好。但在现实任务（例如基于视觉输入的行为学建模或机器人控制）中，环境动态特性 $P$ 是未知的。这时候我们需要动作价值函数$Q(s, a)$ ,它表示在状态 $s$ 下，执行动作 $a$，然后遵循策略 $\pi$，未来能拿到的所有折现奖励期望，贝尔曼方程表示为：$$Q^\pi(s, a) = \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V^\pi(s') \right]$$，它与V(s)的关系表示为:$V(s)$ 是 $Q(s, a)$ 在当前策略下的期望（加权平均）：$$V^\pi(s) = \sum_{a \in A} \pi(a|s) Q^\pi(s, a)$$。如果有了最优的 $Q^*(s, a)$，智能体直接取 $\max_a Q^*(s, a)$ 就能做出最优决策，彻底摆脱了对环境模型 $P$ 的依赖。

### 2.3优势函数A(s, a)
优势函数A(s, a)表示为：$$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$，其含义是在状态s下，采取动作a比平均水平好多少的问题，它是降低策略梯度方差的核心武器。

### 2.4从方程到算法:动态规划
贝尔曼方程给出了数学上的完美等式，而在环境完全已知（即 $P$ 和 $R$ 已知）的前提下，我们如何从算法层面去求解这个问题？通常我们会用到两种方法：
- 策略迭代 (Policy Iteration)： 包含两步。第一步是策略评估（解线性方程组求解 $V^\pi$）；第二步是策略改进（根据当前的 $V^\pi$ 计算出 $Q^\pi$，然后贪心选择 $\max_a Q^\pi$ 产生新策略）。如此反复，直到策略不再改变。
- 价值迭代 (Value Iteration)： 直接暴力利用压缩映射原理，反复执行 $V_{k+1}(s) = \max_a \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V_k(s') \right]$，直到 $V$ 向量收敛。

# 二、无模型强化学习
## 3.Monte Carlo

### 3.1核心思想
环境的转移矩阵P大部分时候是未知的，那我们怎么评估一个状态的价值呢？特卡洛给出的答案极其简单粗暴：用经验代替上帝视角，用大数定律代替严格的概率计算。

智能体遵循当前策略 $\pi$ 在环境中不断交互，直到回合结束，把这条完整的轨迹（Trajectory）记录下来：$$S_1, A_1, R_2, S_2, A_2, R_3, \dots, S_T$$到达终点后，我们就可以真实地计算出某个状态 $s$ 之后累积的真实回报（Return）$G_t$：$$G_t = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{T-t-1} R_T$$只要我们跑的轨迹足够多，根据大数定律，这些真实回报的经验平均值，就会无限逼近真实的期望价值 $V^\pi(s)$：$$V(s) \approx \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_{t}^{(i)}$$这就是蒙特卡洛策略评估的数学本质：用样本均值估计数学期望。

### 3.2Q函数
在第一章中我们提到过Q(s,a),在蒙特卡洛方法中，$Q$ 函数从“配角”变成了绝对的“主角”。假设我们只估计出了状态价值 $V(s)$，当我们要进行策略改进（选择最优动作）时，我们需要计算：$$\pi'(s) = \arg\max_a \sum_{s'} P(s'|s, a) \left[ R(s, a, s') + \gamma V(s') \right]$$你会发现，公式里再次出现了 $P(s'|s, a)$！ 这意味着，如果没有环境模型，即使知道了 $V(s)$，你也无法知道选哪个动作能转移到高价值的状态。因此，蒙特卡洛方法必须直接评估动作价值函数 $Q(s, a)$。我们统计的是：在状态 $s$ 采取动作 $a$ 后，最终获得的平均回报。有了 $Q(s, a)$，策略改进就变成了极其简单的查表操作，彻底踢开了环境模型 $P$：$$\pi'(s) = \arg\max_a Q(s, a)$$

### 3.3探索与利用
由于我们是通过经验来学习，如果自能提总是贪婪地选择当前看起来最好地动作(即 $\max_a Q$)它可能永远只会走那几条固定的轨迹，从而错过真正隐藏在未探索区域的最优解。为了保证所有的 $(s, a)$ 组合都有非零的概率被访问到，蒙特卡洛控制通常采用 $\epsilon$-greedy 策略：以 $1 - \epsilon$ 的概率，选择当前的最优动作（利用）。以 $\epsilon$ 的概率，在所有可能的动作中随机选择一个（探索）。这保证了经验收集的多样性。

### 3.4蒙特卡洛地缺陷
蒙特卡洛虽然直观且绝对无偏（Unbiased，因为它用的是真实的累积回报），但它在工程实现上存在严重的局限性：
- 必须等待回合结束 (Episodic Limit)： 要计算 $G_t$，必须等一条轨迹走到终点 $S_T$。如果你在训练一个自动驾驶模型，难道每次都要等车撞毁了才能更新参数吗？它无法处理连续无终点的任务。
- 方差极大 (High Variance)： $G_t$ 是一条长轨迹上所有奖励的累加。每一步的状态转移和动作选择都充满随机性。这就导致即使在同一个状态 $s$ 采取同一个动作 $a$，每次跑出来的 $G_t$ 数值波动都可能极其剧烈。这种巨大的不确定性会导致网络收敛非常缓慢。

## 补充章节一:方差与偏差

在强化学习中，几乎所有算法的演进，本质上都是在与“方差”和“偏差”这对宿敌作斗争。在机器学习中，我们总希望模型的估计既准（低偏差）又稳（低方差）。但在强化学习评估价值函数时，鱼与熊掌往往不可兼得。

### 补充1.1偏差
偏差代表估计值的期望与真实客观价值之间的系统性差距。在RL中，偏差主要来自于自举 (Bootstrapping)。所谓自举，就是“用猜的价值去更新猜的价值”。如果你的网络当前认为状态 A 的价值是 10，状态 B 的价值是 5，并以此指导后续的更新，但实际上这些估值完全是错的，这种系统性的错误就会顺着网络蔓延，这就是高偏差。

### 补充1.2方差

方差代表估计值在不同采样之间忽高忽低、剧烈波动的程度。在RL中，方差主要来自多步累积的随机性。智能体每走一步，都会经历两次掷骰子：一是策略 $\pi(a|s)$ 的随机性（比如 $\epsilon$-greedy 探索）。二是环境转移概率 $P(s'|s, a)$ 的随机性（比如刮了一阵风，导致即使动作一样，结果也不同）。轨迹越长，随机性就以乘法级别指数级爆炸，导致每次算出来的总回报差异巨大。

### 补充1.3两个极端:MC vs. One-Step TD

我们可以把上一章的蒙特卡洛（MC）和马上要讲的单步时序差分（TD(0)）放在这个天平的两端来对比：- Monte Carlo (零偏差，极高方差)：$$G_t = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{T-t-1} R_T$$MC 绝对诚实。它一直走到回合结束，拿到的 $G_t$ 是真实发生的回报，没有使用任何猜的价值（零自举），所以它是无偏的 (Unbiased)。但是，它累积了从 $t$ 时刻到 $T$ 时刻成百上千步的随机性，导致方差极高。在工程上，高方差意味着神经网络训练极不稳定，Loss 疯狂震荡，收敛极其缓慢。
- TD(0) / 一步时序差分 (高偏差，极低方差)：$$G_{t}^{(1)} = R_{t+1} + \gamma V(S_{t+1})$$TD 极其短视。它只往前真实地走一步，拿到真实的 $R_{t+1}$，然后立刻用网络预估的 $V(S_{t+1})$ 来代替未来的所有奖励。因为它只经历了一步的随机性，所以方差极低，训练非常平稳。但代价是致命的：那个预估的 $V$ 在训练初期完全是瞎猜的，这引入了极大的偏差。

### 补充1.4权衡策略

如果 MC 太飘（高方差），单步 TD 太瞎（高偏差），我们该怎么办？强化学习给出了两种极其优雅的解决方案：
- $n$ 步时序差分 ($n$-step TD)：既然走 1 步偏差大，走到底方差大，那我们就走 $n$ 步！$$G_{t}^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$通过调节 $n$ 的大小，我们可以在方差和偏差之间找到一个最适合当前任务的甜点 (Sweet Spot)。
- 指数加权平均：这是【九、GAE (Generalized Advantage Estimation)】的内容。GAE 并没有死板地选择某一个 $n$，而是利用一个超参数 $\lambda$，把 1 步、2 步、一直到无穷步的估计值做了一个极其精妙的指数加权求和，近乎完美地解决了方差与偏差的权衡问题。这是目前所有主流大模型 RLHF 算法背后的核心支柱。
